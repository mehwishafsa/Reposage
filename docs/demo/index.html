RepoSage is a Claude Code plugin. It maps your codebase with Tree-sitter, explains it in plain English for new teammates, and shows every answer as a path through the code.

What the plugin does

/reposage:scan

Tree-sitter reads Python, JavaScript/TypeScript and Java into a knowledge graph. Deterministic and incremental.

/reposage:summarize

Plain-English summaries, layers and tags, written for a newcomer. Batched and cheap (Haiku).

/reposage:dashboard

The interactive map you see here, as one offline HTML file.

/reposage:chat

Ask a question and get an answer that cites file:line, plus an Answer Path on the map.

/reposage:diff

What your change affects, which tests cover it, and a Low / Medium / High risk.

Install in Claude Code

# add the marketplace (plugin currently on the plugin-version branch)
/plugin marketplace add mehwishafsa/Reposage#plugin-version
/plugin install reposage@reposage

# then, inside any repository
/reposage:scan
/reposage:dashboard
/reposage:chat How does authentication work?

Needs Python 3.10+. The first run sets up a private environment in ~/.reposage/venv (about a minute).
